# 用户使用指南：律师本地匿名化助手

## 适用对象

本指南面向律师、律师助理、法务等非技术用户。

如果您会使用 Word、会下载和解压 zip 文件，就可以使用这个工具。

## 下载

最新版下载页：

[https://github.com/ShengrenHOU/lawyer-local-anonymizer/releases/latest](https://github.com/ShengrenHOU/lawyer-local-anonymizer/releases/latest)

请下载：

```text
LegalAnonymizer.zip
```

不要下载 GitHub 自动生成的 `Source code`，也不要点绿色 `Code` 按钮。

## 第一次使用

1. 解压 `LegalAnonymizer.zip`
2. 双击 `LegalAnonymizer.exe`
3. 程序会自动创建工作文件夹
4. 后续只需要通过程序按钮打开对应文件夹

程序默认工作区：

```text
律师本地匿名化助手/
  01-待匿名化/
  02-已匿名化-可上传AI/
  02-需要复核-暂勿上传/
  03-AI结果文件-待还原/
  04-已还原/
  99-本地映射表-不要上传/
```

## 匿名化客户文件

1. 点击 `放原文件`
2. 把客户文件放入打开的文件夹
3. 等待程序处理
4. 点击 `拿去上传AI`
5. 只上传这里面的匿名化文件

如果文件没有马上处理，可以点击 `重新扫描`。

## 哪些文件能上传

可以上传：

```text
02-已匿名化-可上传AI
```

不能上传：

```text
02-需要复核-暂勿上传
99-本地映射表-不要上传
01-待匿名化
```

`02-需要复核-暂勿上传` 表示程序发现风险或无法确认安全。请先人工检查，不要直接上传给 AI。

`99-本地映射表-不要上传` 里保存真实信息和代号的对应关系，是本地还原用的敏感资料。

## 给 AI 的提示词

每次匿名化成功后，程序会生成 AI 提示词。您也可以点击：

```text
复制AI提示词
```

发送给 AI 时，请让 AI 保持 `[[PERSON_001]]`、`[[COMPANY_001]]` 这类代号不变。AI 如果修改、删除、拆分这些代号，后续还原可能失败。

## 还原 AI 结果

如果 AI 可以下载 Word 或文本结果：

1. 点击 `放AI结果`
2. 把下载的 AI 结果放进去
3. 程序会自动还原
4. 点击 `看还原结果`

如果 AI 只能复制网页回复：

1. 复制 AI 回复
2. 粘贴到程序窗口的大文本框
3. 点击 `粘贴AI回复并还原`
4. 点击 `看还原结果`

## 需要复核时怎么办

如果文件进入 `02-需要复核-暂勿上传`，通常有几种原因：

- 匿名化后仍可能残留姓名、公司、地址等信息
- Word 里有图片、嵌入对象、修订删除文本等无法确认安全的结构
- AI 返回结果破坏了代号
- 程序检测模块发生错误

处理方式：

1. 不要上传该文件
2. 查看同目录或映射表目录里的风险报告
3. 必要时手工清理原文件后重新放入 `01-待匿名化`
4. 如果是 AI 破坏了代号，请重新要求 AI 保留所有 `[[...]]` 代号

## 本地学习记忆

程序会在本地记录已经见过的姓名、公司、地址等内容。以后遇到相同内容时，会更容易识别。

如果需要清空，可以点击：

```text
清空本地学习记忆
```

清空学习记忆不会删除已生成的映射表，也不会影响已经处理过的文件还原。

## 支持的文件

匿名化输入：

- `.docx`
- `.doc`，需要本机 Microsoft Word 支持自动转换
- 可复制文字的 `.pdf`
- `.txt`
- `.md`

AI 结果还原：

- `.docx`
- `.txt`
- `.md`
- 粘贴文本

暂不支持：

- 扫描 PDF
- 图片
- 手写内容
- 盖章图片里的文字
- 加密 PDF

## 重要声明

本工具用于降低上传 AI 前的数据泄露风险，但不能承诺 100% 不遗漏。律师在上传前仍应快速检查匿名化结果。

本工具不会自动上传任何文件。是否上传给 AI，由用户自己决定。
