# 叶律师操作教程：本地匿名化助手

## 1. 这是什么

这是一个只在本地电脑运行的小工具。客户文件先在本地替换成代号，再上传给 Kimi、ChatGPT 等 AI 工具；AI 处理后，工具再在本地把代号还原。

例子：

```text
张三 -> [[PERSON_001]]
上海某某科技有限公司 -> [[COMPANY_001]]
```

AI 只看到代号，看不到真实客户信息。

## 2. 怎么打开

开发者会给您一个已经打包好的程序文件夹。打开文件夹后，双击：

```text
LegalAnonymizer.exe
```

不需要配置账号，不需要联网，不需要写代码。

## 3. 只需要记住 3 步

### 第一步：放原文件

点击：

```text
放原文件
```

把客户的 Word、可复制 PDF、txt 或 md 文件放进去。

如果是旧版 `.doc` 文件，程序会尝试本地转换；如果处理失败，请先用 Word 或 WPS 打开，再另存为 `.docx` 后重新放入。

### 第二步：拿去上传 AI

等程序提示处理完成后，点击：

```text
拿去上传AI
```

只上传这里面的匿名化文件给 Kimi / ChatGPT。

如果原文件是 `.docx`，匿名化文件也会是 `.docx`，会尽量保留原 Word 的段落、表格、页眉页脚和字体。PDF、txt、md 仍会输出文本版。

同时可以点击：

```text
复制AI提示词
```

然后把提示词粘贴给 AI。提示词会要求 AI 不要改动 `[[PERSON_001]]` 这样的代号。

### 第三步：还原 AI 结果

如果 AI 可以下载结果文件：

1. 点击“放AI结果”。
2. 把下载文件放进去。
3. 程序会自动还原。
4. 点击“看还原结果”。

如果 AI 不能下载，只能复制网页回复：

1. 把 AI 回复复制到程序窗口的大文本框。
2. 点击“粘贴AI回复并还原”。
3. 点击“看还原结果”。

通常不需要手动选择映射表。只有程序提示无法自动还原时，再点击“手动选择映射表还原”。

如果 AI 把 `[[PERSON_001]]` 这类代号删掉、改坏或新增了程序不认识的代号，还原结果会进入“需要复核”。这种结果不要直接使用，需要重新让 AI 保留原代号后再处理。

## 4. 文件夹不用清理

您可以长期保留文件夹里的历史文件。程序会记录哪些文件已经处理过，不会每次启动都重复处理。文件内容改变后，程序会重新处理。

## 5. 本地学习记忆

程序会把已经处理过的姓名、公司名、地址等内容记在本机本地记忆里。以后再遇到相同内容，会更容易自动识别。

本地记忆会记录是否启用、出现次数和来源文件，后续可以用于排查和治理错误学习项。

这个记忆只保存在本地电脑。如果您不想继续保留，可以点击：

```text
清空本地学习记忆
```

清空学习记忆不会删除已经生成的脱敏对照表，也不会影响已经处理过的文件还原。

## 6. 程序会创建哪些文件夹

第一次运行后，程序会自动创建：

```text
律师本地匿名化助手/
  01-待匿名化/
  02-已匿名化-可上传AI/
  02-需要复核-暂勿上传/
  03-AI结果文件-待还原/
  04-已还原/
  99-本地映射表-不要上传/
```

其中：

```text
01-待匿名化
放客户原始文件。

02-已匿名化-可上传AI
只上传这里面的文件给 AI。

02-需要复核-暂勿上传
程序发现可能还有未脱敏内容。这里面的文件不要上传给 AI。

03-AI结果文件-待还原
AI 下载结果放这里。

04-已还原
看最终还原结果。

99-本地映射表-不要上传
保存真实信息和代号的对照表，绝对不要上传给 AI。
```

每次处理完成后，程序还会生成一个“处理结果说明.txt”，告诉您这个文件是否可以上传、对应的提示词和对照表在哪里。

## 7. 绝对不要上传的内容

不要上传这个文件夹：

```text
99-本地映射表-不要上传
```

这个文件夹里有真实信息和代号的对照关系。

## 8. 支持和不支持的文件

目前支持：

```text
Word: .docx
旧版 Word: .doc，需本机 Microsoft Word 支持自动转换；失败时请另存为 .docx
可复制 PDF: .pdf
纯文本: .txt
Markdown: .md
```

目前不支持：

```text
扫描 PDF
图片
手写内容
盖章图片里的文字
加密 PDF
```

如果 PDF 里的文字不能复制，这一版一般也识别不了。

## 9. 一句话版流程

```text
放原文件 -> 拿匿名化文件上传 AI -> AI 结果放回或粘贴 -> 看已还原结果
```
